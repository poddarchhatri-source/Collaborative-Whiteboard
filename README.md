# SynCanvas Collaborative Whiteboard

GitHub repository: https://github.com/poddarchhatri-source/Collaborative-Whiteboard

SynCanvas is organized as separate server and client applications, with source
code and project documentation in the folders below.

## Download the Windows `.exe` files

You can download the Windows files without running them:

1. Open the repository's **Actions** tab and select a successful **Build
   desktop applications** run.
2. Under **Artifacts**, download `syncanvas-windows-server` and
   `syncanvas-windows-client`.
3. Extract each ZIP file. The executables are:
   - `01_Server_Application/syncanvas-windows-server/server.exe`
   - `02_Client_Application/syncanvas-windows-client/client.exe`

Do not double-click the files if you only want to keep or transfer them.
Windows `.exe` files run on Windows, not macOS or Linux.

## Linux builds

Linux builds are available from the `syncanvas-linux-server` and
`syncanvas-linux-client` artifacts in the same Actions run. They are Linux
executables, not `.exe` files. Run them on a Linux computer.
