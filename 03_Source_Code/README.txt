SynCanvas Source Code

REQUIREMENTS
- Python 3.11 or newer
- A network connection between computers that share a board

RUN FROM SOURCE
Open a terminal in this folder and install the dependencies:

  python -m venv .venv
  source .venv/bin/activate          (macOS/Linux)
  .venv\Scripts\activate.bat         (Windows Command Prompt)
  python -m pip install -e ".[dev]"

Start the server control centre:

  python run_server.py

Click Start Server in its window, then open a second terminal and start the
client:

  python run_client.py

BUILD NATIVE APPLICATIONS
Install the development dependencies above, then run:

  python build_app.py

Build on the target operating system. The server and client outputs are placed
in the corresponding numbered application folders at the project root.
Windows and Linux builds are also generated by the GitHub Actions workflow.
