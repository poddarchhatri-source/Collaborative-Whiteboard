SynCanvas runtime requirements
==============================

Required:
- Python 3.11 or newer
- PySide6 >= 6.6 and < 7
- Pillow >= 10 and < 14

The exact package list is in requirements.txt.

Manual install:
1. Create a virtual environment:
   python3 -m venv .venv
2. Activate it:
   macOS/Linux: source .venv/bin/activate
   Windows:     .venv\Scripts\Activate.ps1
3. Install packages:
   python -m pip install -r requirements.txt

On macOS or Windows, the Run_Client / Run_Server launchers can create the
virtual environment and install missing packages automatically on first use.
